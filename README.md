 **Heart Disease Risk and Patient Health Analysis**

 **Project Overview**
A data analytics project that analyzes clinical patient records to identify heart disease risk factors and patient health outcomes using Power BI.

**Objectives**
- Identify high-risk patient groups.
- Analyze the impact of diabetes, smoking, and blood pressure.
- Create an interactive Power BI dashboard.

 **Technologies Used**
- Python (Pandas, NumPy)
- Power BI
- DAX

 **Dataset**
- UCI Machine Learning Repository
- Kaggle Heart Disease Dataset

 **Key Features**
Age, Sex, Chest Pain Type, Blood Pressure, Cholesterol, Maximum Heart Rate, Ejection Fraction, and Target.

 **Workflow**
1. Data Collection
2. Data Cleaning
3. Data Preprocessing
4. Data Visualization
5. Dashboard Development

 **Dashboard Features**
- Total Patients
- Heart Disease Rate (%)
- Average Ejection Fraction
- Survival Count
- Interactive filters and charts

**Key Insights**
- Disease prevalence increases beyond age 45.
- Male cohorts show a higher diagnosis profile in the dataset.
- Clinical indicators help analyze patient health.

**Future Scope**
Integration of Machine Learning models such as Random Forest and Logistic Regression.
